# News Article Popularity Analysis

**EDAV Course-End Project**  
Exploratory Data Analysis & Visualization (22ADC31N)

## Overview
This project explores the characteristics associated with the popularity of online news articles using exploratory data analysis, statistical summaries, and data visualization.

## Dataset
The project uses the **Online News Popularity** dataset from the UCI Machine Learning Repository. It contains article-level features, including headline and content characteristics, publication-day indicators, news categories, and the number of shares.

**Target variable:** `shares`

The dataset must be uploaded separately to Google Colab before running the notebook.

## Tools and Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Google Colab

## Notebook
Open `news_popularity_analysis.ipynb` in this repository to view the analysis, code, outputs, and visualizations.

To run the notebook, open it in Google Colab, upload `OnlineNewsPopularity.csv` when prompted by the notebook's data-loading cell, and run the cells in order.

## Project Objectives
- Examine the distribution of article shares.
- Explore article characteristics and news categories.
- Compare popularity across publication days.
- Investigate relationships between article features and popularity.
- Communicate findings through visualizations.

## Note
The analysis identifies descriptive patterns and associations. It does not establish causal relationships between article features and popularity.
